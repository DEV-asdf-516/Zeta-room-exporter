# Zeta Room Exporter

현재 Zeta AI에 로그인된 브라우저 세션으로 열린 Room의 전체 대화 또는 두 북마크 사이를 JSON/TXT 파일로 저장하는 Manifest V3 Chrome 확장 프로그램입니다.

수집한 페이지는 즉시 IndexedDB에 저장됩니다. API 오류나 서비스 워커 종료로 작업이 멈추면 팝업의 **이어받기**로 마지막 성공 cursor부터 계속할 수 있습니다. 5,000개 이상이거나 8 MiB 이상인 결과는 파일이 분할되어 다운로드 됩니다.

확장 프로그램은 작업 시작 전과 각 페이지 저장 전에 브라우저 저장소 여유 용량을 확인합니다. 공간이 적으면 팝업에 경고하고, 체크포인트를 안전하게 저장할 수 없으면 디스크 공간을 확보할 때까지 작업을 중단합니다.

Zeta 메시지 본문을 마우스 오른쪽 버튼으로 누르고 **북마크 추가**를 선택하면, 북마크를 생성하고 목록에서 다시 검증합니다.

## 새로 추가된 기능

- **끊겨도 이어서 저장**: 대화 내용을 저장하다가 중간에 멈춰도, 처음부터 다시 하지 않고 멈춘 부분부터 이어서 저장할 수 있습니다.
- **긴 대화는 여러 파일로 나눠 저장**: 대화가 너무 길면 파일 하나로 저장할 경우 열리지 않을 수 있어, 여러 개의 작은 파일로 나눠 저장합니다. 이때 어떤 파일부터 봐야 하는지 안내하는 목록도 함께 저장됩니다.
- **북마크 구간만 저장 가능**: 대화 전체가 아니라, 북마크 구간만 골라 저장할 수 있습니다.
- **북마크 추가 기능**: Zeta의 메시지에서 마우스 오른쪽 버튼을 눌러 "북마크 추가"를 선택하면, 북마크 추가가 가능합니다.
- **저장 공간 부족 시 경고**: 기기의 저장 공간이 부족하면 작업을 시작하기 전에 미리 알려주고, 이미 저장된 내용은 그대로 둔 채 작업을 잠시 멈춥니다.
- **문제 발생 시 기록 저장**: 작업이 멈추거나 실패했을 때, 원인을 확인할 수 있는 기록을 남겨두며, 더 이상 필요 없는 작업은 삭제할 수 있습니다.

## 개선 및 수정된 부분

- Zeta의 북마크 목록에서 날짜와 대화 내용 일부가 안정적으로 보이도록 고쳤습니다.
- 이미 북마크로 표시된 메시지를 실수로 중복 표시하지 않도록 했고, 북마크 추가가 잘 됐는지 다시 확인해서 알려줍니다.
- 매우 짧은 시간 차이로 연이어 온 메시지들도 실제 순서에 맞게 정확히 정렬되도록 했습니다.
- 긴 대화를 저장할 때 컴퓨터(브라우저)가 버벅이거나 멈추는 문제를 줄였습니다.
- Zeta 서버가 잠시 응답하지 않을 때, 자동으로 기다렸다가 다시 시도하며 현재 진행 상황을 화면에 보여줍니다.
- 저장 형식과 구간 선택 화면의 디자인을 통일했고, 선택한 구간과 시작·끝 지점이 더 잘 보이도록 개선했습니다.
- 문제 기록에 로그인 정보나 대화 내용, 서버의 내부 위치 정보 같은 민감한 정보가 남지 않도록 보호 조치를 했습니다.


## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.
4. Zeta AI의 대화방을 연 뒤 확장 아이콘을 누릅니다.
5. 저장 형식을 고릅니다.
   - **JSON**: 대화 정보를 JSON 파일로 저장합니다.
   - **TXT**: `@이름: 메시지` 형식의 텍스트 파일로 저장합니다.
6. **현재 Room 내보내기**를 누릅니다.
