# Zeta Room Exporter

현재 Zeta AI에 로그인된 브라우저 세션으로 열린 Room의 전체 대화를 JSON 파일로 저장하는 Manifest V3 Chrome 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.
4. Zeta AI의 대화방을 연 뒤 확장 아이콘을 누릅니다.
5. 저장 형식을 고릅니다.
   - **JSON**: 대화 정보를 JSON 파일로 저장합니다.
   - **TXT**: `@이름: 메시지` 형식의 텍스트 파일로 저장합니다.
6. **현재 Room 내보내기**를 누릅니다.
